          Configurações
          
        
      

        
      
          Cola rápida de comandos
          
      
            
      {site: url} · domain · path · protocol · query · hash
      
            
      Partes da URL da página atual.
      
            
      {site: title} · {site: selection}
      
            
      Título da aba e texto selecionado na página.
      
            
      {site: text; selector=.cliente .nome}
      
            
      Texto do 1º elemento que casa com o seletor CSS. Use html para o HTML e multiple=yes para todos.
      
            
      {time: DD/MM/YYYY HH:mm} · {time: LL}
      
            
      Data e hora atuais. Texto fixo vai entre colchetes: {time: [Hoje é] dddd}.
      
            
      {clipboard}
      
            
      Texto copiado (Ctrl+C).
      
            
      {=extractregex({site: query}, "id=([^&]+)")}
      
            
      Extrai um pedaço do texto com uma expressão regular (1º grupo entre parênteses).
      
            
      {=catch({site: text; selector=.nome}, "Não encontrado")}
      
            
      Se o que está dentro falhar, usa o texto padrão.
      
            
      {id=extractregex({site: path}, "/([^/]+)$")} e depois {=id}
      
            
      Guarda um valor numa variável e usa depois.
      
            
      \{ e \}
      
            
      Chaves literais (quando não é um comando).
